# 从零到上线：一个真实项目教你多 Agent 协作与全栈开发

> 本教程基于真实项目「票夹通」（网页版发票票夹管理）的完整开发历程改编。
> 项目由 1 位人类 + 1 个主 Agent + 6 个职能子 Agent 协作完成：
> 31 份设计文档 → 技术验证 → 后端 19 项测试全绿 → 前端 32 项 E2E 全绿 → 生产部署工件。
> 教程中的每一行代码、每一个坑，都来自这次真实开发，可在本仓库中找到对应文件。

## 这本教程为谁而写

| 你是…… | 你将学到 |
| --- | --- |
| 想了解**多 Agent 协作**的人 | 如何把一个想法拆给多个 AI 角色执行，如何用质量门禁、决策记录、契约链保证它们不跑偏 |
| **刚接触编程**的新手 | 一个软件从需求到上线到底要经历什么（比直接学语法更重要的全景认知） |
| 想学 **Java 技术栈**的人 | Spring Boot / Maven / MyBatis-Flex / PostgreSQL / Flyway / Spring Security 的实战用法 |
| 想学 **Web 技术栈**的人 | React / TypeScript / Vite / Tailwind / 路由 / 表单 / 与后端联调的完整链路 |

**前置要求**：会开关电脑、能照着命令行敲命令。教程假设你零基础，每个概念第一次出现都会用一句话解释。

## 怎么使用本教程

1. **按序阅读**（第 1→8 章，故事线完整）；
2. **对照真实仓库**：每章都标注了对应文件路径（`workspaces/P20260914-1728-网页版票夹管理发票/…`，下文简称 `WS/`），强烈建议边读边打开看；
3. **动手练习**：每章末尾有 1-2 个小练习，全部可在本机完成；
4. 本地跑起来整个项目只要三条命令（见第 7 章附录）。
