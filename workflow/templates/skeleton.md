# 兜底文档骨架（主 Agent 使用）

当某个 subagent 校验不合格且修复轮仍失败时，主 Agent 按此骨架为**每份缺失/不达标文档**
生成兜底文件（文件名与路径必须符合角色必交清单），并把该阶段记为 `degraded`。

使用方法：复制下方模板，替换 `{角色名}`、`{文档说明}`、`{项目ID}`、`{用户需求}`。

---

```markdown
# [待补充] {文档说明}

> ⚠️ **兜底文档**：{角色名}阶段的产出未通过质量门禁，本文件由主 Agent 按模板生成，
> 用于保证交付完整性。**内容需要人工补充或重跑该阶段。**

## 背景

- 项目：{项目ID}
- 用户需求：{用户需求}
- 生成时间：（填写当前时间）

## 待补充

- [ ] 按 {角色名} 职责补齐本文档完整内容（参考 `.zcode/agents/{角色}.md` 中的必交要求）
- [ ] 与上下游角色文档对齐口径（见工作区其他目录）
- [ ] 完成后删除本提示区块

## 重跑方式

```
/flow:resume {项目ID} --retry-degraded
```
```
