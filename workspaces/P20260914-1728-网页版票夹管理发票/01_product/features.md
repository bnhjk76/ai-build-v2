## 1. MoSCoW 判定规则

- **Must**：MVP 成功不可缺，缺失即判定里程碑验收不通过。
- **Should**：MVP 内应有，资源不足时可延后至 M2 末期，但需在 issues 记录。
- **Could**：体验增强项，工期富余才做，不阻塞验收。
- **Won't（本期不做）**：与章程 §4.2 范围外一致。
- 里程碑映射：M1 = 账号 + 录入 + 列表 + 检索；M2 = 汇总 + 导出 + 附件 + 回收站。

## 3. 功能详细定义与验收标准

验收标准统一格式：**Given**（前置）/ **When**（操作）/ **Then**（预期）。标注「异常」的条目为异常路径验收。

### F01 注册（Must / M1）

**描述**：新用户使用邮箱或手机号 + 密码创建账号，账号即私有票夹的归属主体。

**规则**：
- 账号标识：邮箱（含格式校验）或手机号（中国大陆 11 位，开学号格式校验）；二选一，注册后不可更换（MVP）。
- 密码：8–20 位，必须同时包含字母与数字；需二次输入确认。
- 同一标识仅允许注册一个账号。

**验收标准**：
- Given 访客未登录，When 提交合法邮箱 + 合规密码，Then 注册成功、自动登录、进入空票夹首页，并触发埋点 `account_register_success`。
- Given 已注册邮箱，When 再次注册，Then 保存被拒，提示「该邮箱已注册，请直接登录」，埋点 `account_register_fail{reason:dup_account}`。
- Given 密码为 6 位纯数字，When 提交，Then 前端即时提示密码规则，不发起请求。
- Given 手机号不足 11 位 / 邮箱缺「@」，When 提交，Then 即时格式错误提示，定位到出错字段。

### F02 登录（Must / M1）

**描述**：已注册用户凭账号标识 + 密码登录，进入自己的票夹。

**规则**：登录态保持 7 天（假设 A5）；连续 5 次失败锁定 10 分钟；锁定期间正确密码也不可登录并提示剩余时间。

**验收标准**：
- Given 已注册用户，When 输入正确邮箱/手机号与密码，Then 登录成功跳转票夹列表，埋点 `account_login_success`。
- Given 密码错误，When 提交，Then 提示「账号或密码错误」（不泄露哪个字段错），埋点 `account_login_fail{reason:wrong_password}`。
- Given 连续 5 次失败，When 第 6 次尝试（即使密码正确），Then 拒绝登录并提示「账号已锁定，请 10 分钟后重试」，埋点 `account_login_fail{reason:locked}`。
- Given 未登录用户直接访问票夹 URL，When 页面加载，Then 302 跳转登录页，登录成功后回跳原 URL。

### F03 退出（Must / M1）

**验收标准**：
- Given 已登录用户，When 点击「退出」，Then 服务端会话失效、前端清除本地登录态，回到登录页。
- Given 已退出用户，When 点击浏览器「后退」进入票夹页，Then 不展示任何发票数据（重新跳转登录页）。

### F04 手工录入发票（Must / M1）—— 核心功能

**描述**：表单录入一条开票记录（开票方视角），字段与规则如下（对应 PRD 假设 A1/A2）：

| 字段 | 必填 | 规则 | 说明 |
| --- | --- | --- | --- |
| 开票日期 | 是 | 日期控件，≤ 今天 | 不允许未来日期 |
| 抬头（购买方名称） | 是 | 1–100 字符 | 检索主字段 |
| 发票号码 | 是 | 8–20 位数字 | 兼容数电 20 位号码 |
| 发票代码 | 否 | ≤20 位数字/字母 | 数电票无代码，故选填 |
| 金额（不含税） | 是 | > 0，两位小数，上限 99,999,999.99 | 元 |
| 税额 | 是 | ≥ 0，两位小数 | 免税场景填 0 |
| 价税合计 | 自动 | 金额 + 税额，只读展示 | 前端实时计算 |
| 票种 | 是 | 专票 / 普票 | 与「介质」组合成类型（A1） |
| 介质 | 是 | 电子 / 纸质 | 同上 |
| 状态 | 是 | 正常 / 作废 / 红冲，默认「正常」 | 影响汇总口径（A3） |
| 备注 | 否 | ≤ 200 字 | 自由文本 |

**验收标准**：
- Given 已登录用户，When 依次填写全部合法字段并提交，Then 保存成功、返回列表且新记录出现在顶部（按开票日期倒序位置），埋点 `invoice_create_success`，Toast 提示「已保存」。
- Given 任一必填项为空 / 金额为 0 / 日期为未来，When 提交，Then 不发起保存请求，逐字段行内提示错误原因，埋点 `invoice_create_fail{reason:validation}`。
- Given 新注册用户首次进入，When 从点击「新增发票」到保存成功，Then 端到端耗时 ≤ 2 分钟（G1，可用性测试脚本验证：字段数 ≤ 11、默认值合理）。
- Given 网络中断，When 提交，Then 保存失败有明确错误提示且表单内容不丢失（本地暂存），埋点 `invoice_create_fail{reason:network}`。

### F05 编辑发票（Should / M2）

**验收标准**：
- Given 已存在记录，When 从详情页进入编辑并修改金额后保存，Then 列表与详情即时反映新值，保留创建时间、更新「更新时间」。
- Given 编辑保存时校验失败，Then 与 F04 相同的行内错误规则。
- 降级方案（若 M2 不做）：用户通过「删除 + 重录」修正，support FAQ 需写明。

### F06 删除发票（Must / M2）

**验收标准**：
- Given 列表或详情页，When 点击「删除」，Then 弹出二次确认（说明「将移入回收站，30 天内可恢复」）；确认后记录从列表消失、进入回收站（软删除），埋点 `invoice_delete_success`。
- Given 取消二次确认，When 选择「取消」，Then 记录保留、无任何变化。
- 异常：附件随记录一并进入回收站存续（联动 F11/F12）。

### F07 票夹列表与详情（Must / M1）

**描述**：按开票日期倒序的全量列表 + 分页 + 点击查看详情。

**规则**：排序 = 开票日期倒序，同日按创建时间倒序（假设）；每页 20 条（假设 A6）；列表列：开票日期、抬头、类型（票种+介质标签）、状态、价税合计、附件标记；空列表展示空状态（F14）。

**验收标准**：
- Given 账号有 45 条记录，When 打开票夹，Then 第 1 页展示最近 20 条、分页控件显示共 3 页，埋点 `invoice_list_view{page:1,total:45}`。
- Given 任意两条记录开票日期不同，When 列表渲染，Then 日期新者在上。
- Given 点击某条记录，When 详情页加载，Then 展示该记录全部 11 个字段 + 附件缩略图，埋点 `invoice_detail_view`。
- Given 用户 A 与用户 B 各有记录，When A 查看列表，Then 仅见自己的记录（G4 账号隔离，tech 需提供越权测试用例）。

### F08 多维筛选与检索（Must / M1）—— 核心功能

**描述**：组合筛选票夹，条件之间为 AND 关系。

**筛选条件与口径**：

| 条件 | 控件 | 口径 |
| --- | --- | --- |
| 月份 | 年月选择器 | 开票日期落在所选自然月 |
| 抬头关键字 | 文本输入 | 抬头字段包含（contains，不区分大小写） |
| 金额区间 | 最小值 / 最大值 | 作用于价税合计（A4）；min ≤ max |
| 类型 | 电子 / 纸质 / 专票 / 普票 | 分别映射到介质维度、票种维度（A1），可多选 |
| 状态 | 正常 / 作废 / 红冲 | 精确匹配，可多选 |

**验收标准**：
- Given 1000 条记录，When 应用「2026-08 + 抬头含『科技』+ 金额 1000–5000 + 电子 + 正常」组合筛选，Then 结果 ≤ 1 秒返回且全部满足条件（G2），埋点 `invoice_filter_apply{dims:month,title,amount,type,status,has_result:true}`。
- Given 筛选条件在生效中，When 点击「清除筛选」，Then 恢复全量列表、筛选控件复位。
- Given 筛选无结果，When 结果渲染，Then 展示空态文案「没有符合条件的发票，试试调整筛选」，埋点 `invoice_filter_apply{has_result:false}`。
- Given 金额区间填 min > max，When 应用筛选，Then 即时提示「最小金额不能大于最大金额」。
- Given 筛选结果非空，When 滚动或翻页，Then 筛选条件保持（不因翻页丢失）。

### F09 汇总统计（Must / M2）

**描述**：独立汇总页，回答「本月 / 本年开了多少」。

**内容**：
- 卡片一「本月」：本月开票张数、有效金额合计（口径 A3：正常票计入，红冲按负数冲减，作废不计金额只计总张数）。
- 卡片二「本年」：本年张数、有效金额合计、作废张数、红冲张数。
- 类型分布图：按票种 × 介质（电子普票 / 纸质普票 / 电子专票 / 纸质专票）的张数与金额分布。

**验收标准**：
- Given 本月正常 8 张合计 40,000 元、红冲 1 张 -2,000 元、作废 1 张 1,000 元，When 打开汇总页，Then 本月张数 = 10、有效金额 = 38,000 元，作废/红冲张数分列展示，埋点 `stats_view{range:month}`。
- Given 本年无任何记录，When 打开汇总页，Then 展示 0 值与空分布图，不报错。
- Given 跨年数据存在，When 查看本年卡片，Then 仅统计当前自然年（口径以服务器时区东八区为准）。

### F10 CSV 导出（Must / M2）

**规则**：入口两处——列表页「导出当前筛选」、汇总页「导出明细」；导出内容 = 当前筛选结果（汇总页入口 = 汇总口径的明细）；编码 UTF-8 带 BOM；单次 ≤ 5000 条（假设 A6）；文件名 `票夹通导出_YYYYMMDD_HHmmss.csv`。

**CSV 列**：开票日期、发票代码、发票号码、抬头、票种、介质、状态、金额、税额、价税合计、备注、录入时间。

**验收标准**：
- Given 筛选出 25 条记录，When 点击导出，Then 下载的 CSV 用 Excel 直接打开中文不乱码、共 26 行（表头 + 25 数据行）、列顺序与定义一致，埋点 `export_success{rows:25}`。
- Given 无筛选条件，When 从列表导出，Then 导出该账号全量记录（≤ 5000 条）。
- Given 筛选结果超过 5000 条，When 点击导出，Then 提示「超过单次导出上限 5000 条，请缩小筛选范围」，埋点 `export_fail{reason:over_limit}`。
- Given 导出内容，When 检查敏感字段，Then CSV 不脱敏（本人主动导出场景，见 PRD Q2 边界）。

### F11 附件上传与管理（Should / M2 必达）

**规则**：格式 jpg / jpeg / png / webp / pdf；单个 ≤ 10MB；每条记录 ≤ 3 个；支持在上传后删除单个附件；附件仅记录所有者可查看。

**验收标准**：
- Given 录入或编辑页，When 上传 3MB 的发票图片，Then 展示上传进度并成功后出现缩略图，埋点 `attachment_upload_success`。
- Given 选择 15MB 的 PDF，When 上传，Then 即时拒绝并提示「单个附件不能超过 10MB」，埋点 `attachment_upload_fail{reason:oversize}`。
- Given 已挂 3 个附件，When 上传第 4 个，Then 上传入口置灰并提示「每条发票最多 3 个附件」，埋点 `attachment_upload_fail{reason:count_limit}`。
- Given 选择 .zip 文件，When 上传，Then 提示「仅支持图片（jpg/png/webp）或 PDF」，埋点 `attachment_upload_fail{reason:format}`。
- Given 记录被删除后恢复（F12），When 查看附件，Then 附件完整恢复。

### F12 回收站与恢复（Must / M2）

**规则**：回收站独立入口；按删除时间倒序；每条展示删除时间与「剩余可恢复天数」；30 天到期自动物理清除（含附件）；回收站内记录不可编辑、不参与列表 / 筛选 / 汇总 / 导出。

**验收标准**：
- Given 删除 2 条记录，When 打开回收站，Then 可见 2 条记录及各自剩余天数（≤ 30），埋点 `recycle_view`。
- Given 回收站内一条记录（剩余 18 天），When 点击「恢复」，Then 记录回到票夹列表原排序位置、回收站消失，埋点 `recycle_restore_success`。
- Given 记录已删除 31 天，When 打开回收站，Then 该记录已被自动清除、不可恢复。
- Given 回收站内记录，When 点击「彻底删除」并确认，Then 记录与附件立即物理清除、不可恢复。

### F13 敏感字段脱敏（Must / 横切 M1 起）

**规则**（PM 底线，界面细节由 designer 细化）：发票号码在列表默认掩码（保留末 4 位，如 `****5678`）；提供「显示 / 隐藏」切换（记忆用户偏好）；顶栏账号手机号 / 邮箱脱敏（如 `138****1234`、`a***@x.com`）；记录详情页与导出 CSV 不脱敏（本人已登录场景）。

**验收标准**：
- Given 列表加载完成，When 未点击显示切换，Then 所有发票号码呈掩码态，旁窥无法读全号。
- Given 点击「显示」，When 列表刷新，Then 本会话内号码完整显示，再次点击可切回。
- Given 全站任意页面，When 抓包检查，Then 所有请求均走 HTTPS（G4，与 ops 验收清单互查）。

### F14 空状态引导（Could / M2）

**验收标准**：Given 新注册用户空票夹，When 打开首页，Then 展示「录入你的第一张发票」引导与入口按钮，埋点 `empty_state_view`。

### F15 抬头历史联想（Could / M2）

**验收标准**：Given 用户已录入过抬头「XX科技有限公司」，When 新建记录输入「科技」，Then 联想下拉出现该历史抬头，点选即填入。
