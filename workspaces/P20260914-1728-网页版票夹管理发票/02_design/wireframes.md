# 线框图 —— 票夹通（TicketWallet）

> 文档版本：v1.0 ｜ 撰写日期：2026-09-14 ｜ 撰写角色：designer（UI/UX 设计师） ｜ 状态：待评审
> 上游依据：`./information-architecture.md`（导航结构）、`./pages.md`（P01–P08）、`./design-spec.md`（Tokens）
> 线框图表达布局结构与信息层级，不含最终视觉样式；所有尺寸/颜色以 design-spec Tokens 为准。

---

## 1. 背景

本文档用 ASCII 线框图固定 7 个核心界面的结构：登录/注册、票夹列表（桌面与移动双形态）、发票表单、发票详情、汇总统计、回收站，以及关键弹窗。线框图的作用是让 tech 在实现前对「什么区域放什么」达成无歧义共识，并作为 E2E 走查的基准截图对照。

**画布约定**：桌面按内容区最大 1200px、移动按 375px 宽示意。图例：`[ ]` 按钮/输入，`( )` 单选胶囊，`{ }` 多选胶囊，`▶` 当前选中，`…` 省略重复项，`▓` 骨架/占位。

## 9. W8 关键弹窗与 Toast

```
删除确认（列表/详情）              彻底删除确认（回收站）
┌────────────────────┐           ┌────────────────────┐
│ 删除这张发票？      │           │ ⚠ 彻底删除？       │
│ 将移入回收站，      │           │ 删除后不可恢复，    │
│ 30 天内可恢复。     │           │ 附件同时清除。      │
│      [取消][删除]  │           │    [取消][彻底删除] │
└────────────────────┘           └────────────────────┘

导出超限警示                       Toast（成功/错误）
┌────────────────────┐           ═════════════════════
│ 超过单次导出上限     │           ● 已保存        (4s)
│ 5000 条，请缩小     │           ● 保存失败，请重试 (8s)
│ 筛选范围。          │           ═════════════════════
│ [知道了][去按月筛选]│           桌面右上角/移动顶部居中
└────────────────────┘
```

两级删除文案刻意区分（「30 天内可恢复」vs「不可恢复」），对应 interactions.md R5 与术语表。
