## 1. 背景

本文定义票夹通前后端之间的 HTTP 契约：统一约定（版本/包络/分页/时间/金额）、核心资源、全部接口、错误码规范与安全约定。所有接口与 features.md 的验收标准（Given/When/Then）一一对应，qa 可直接按本文断言。

**v2.0 契约治理机制**：本文是语义唯一口径（人读）；`contracts/openapi.json` 是机器可读单一契约源（springdoc 从 Controller 注解导出、入库存证、orval 生成前端类型与客户端、CI 三道防线检测漂移——工具链详见 tech-stack §7）。两者关系：**语义冲突时以本文为准并修 OpenAPI 注解**；接口增删/字段变更必须同步本文 §4/§6 与契约工件，缺一即 CI 红。

## 2. 统一约定（继承 v1.0，实现落点换 Java）

| 项 | 约定 | Java 侧实现落点 |
| --- | --- | --- |
| 基路径 | `/api/v1`（破坏性变更升 v2） | Controller `@RequestMapping("/api/v1/…")` |
| 传输 | 全站 HTTPS（Caddy 自动签发）；同源部署，无 CORS | — |
| 请求格式 | `application/json`（附件上传除外：`multipart/form-data`） | — |
| 认证 | Cookie `tw_session`（HttpOnly; Secure; SameSite=Lax）——Spring Session JDBC 下发；**所有写接口额外要求头 `X-Requested-With: XMLHttpRequest`**（CSRF 双保险，缺失 → `403 AUTH_006`，见 §6 规范细则 4） | XRequestedWithFilter |
| 响应包络 | 成功：`{ "data": <资源或null> }`（2xx）；失败：`{ "error": { "code", "message", "details": [<字段级错误>] } }`（4xx/5xx） | `ApiResponse<T>` 记录 + GlobalExceptionHandler |
| 时间 | 传输一律 ISO 8601 UTC（`2026-09-14T08:00:00Z`）；开票日期 `YYYY-MM-DD`；业务口径（自然月/年、≤今天）服务端固定东八区 | Jackson JavaTimeModule；`TimeZones` 常量 |
| 金额 | 字符串两位小数 `"4000.00"`（避免浮点；PG numeric(12,2) 直映射） | Jackson 全局 BigDecimal ↔ 两位小数字符串模块 |
| 分页 | `page`（从 1 起）+ `page_size`（默认 20，上限 100）；响应含 `total`。**桌面分页与移动「加载更多」共用同一接口** | QueryWrapper LIMIT/OFFSET + COUNT |
| 越权语义 | 访问他人/不存在的资源一律 `404 INV_001`（不返回 403，防存在性探测——IA §6） | service `loadOwned(id, userId)` 谓词纪律 |
| 幂等性 | 写接口防重复：前端按钮 loading 禁用 + 服务端不额外做幂等键（MVP 取舍，记入遗留，继承） | — |
| 路径参数 | 资源 id 为 UUID 字符串 | — |

## 3. 核心资源（继承 v1.0）

| 资源 | 说明 | 关键字段与口径 |
| --- | --- | --- |
| User | 账号（邮箱或手机号二选一，注册后不可换） | `account`、`accountType`（email/phone）；密码仅入参不回传 |
| Invoice | 开票记录（11 字段，IA §4.1） | `invoiceCode?`（≤20 位数字/字母）、`invoiceNumber`（8–20 位数字）、`issuedDate`、`title`（1–100）、`amount`（>0）、`taxAmount`（≥0）、`totalAmount`（服务端重算=amount+taxAmount，**前端只传前两项**）、`category`（special/general）、`medium`（electronic/paper）、`status`（normal/voided/reversed）、`remark?`（≤200） |
| Attachment | 附件（≤3 个/记录，≤10MB） | `filename`、`mimeType`、`size`、`createdAt`；文件本体经 `storageKey` 间接访问 |
| StatsSummary | 汇总投影（只读聚合） | 口径 A3：`有效金额 = Σ(正常 total) − Σ(红冲 total)`；`有效张数 = 正常+红冲`；`作废`只计张数 |
| Event | 埋点事件 | `name`（字典见 features/interactions）、`reason?`、`dims?` |

## 4. 接口清单（22 端点 = 21 业务/运维 + 1 契约端点）

### 4.1 认证 auth（F01–F03，M1）

| 方法 路径 | 说明 | 请求/响应要点（继承 v1.0） |
| --- | --- | --- |
| `POST /auth/register` | 注册并自动登录 | 入参 `{account, password}`；服务端识别 accountType 并校验格式；成功 `201` + Set-Cookie，`data` 含脱敏账号 `"a***@x.com"`；重复注册 `409 AUTH_004`（message 含「请直接登录」引导） |
| `POST /auth/login` | 登录 | 入参 `{account, password}`；错误统一 `401 AUTH_001`「账号或密码错误」（不泄露哪个字段错）；第 6 次起 `423 AUTH_002`，`details` 含 `retryAfterMinutes`（前端禁用按钮并显示剩余时间）；成功返回 `{account(脱敏), accountType}` |
| `POST /auth/logout` | 退出（需登录） | **删除 SPRING_SESSION 行 + 清 Cookie**（Spring Session invalidate 即删行）；`204` |
| `GET /auth/me` | 当前会话（需登录） | `200 {account(脱敏), accountType, expiresAt}`；会话失效 `401 AUTH_003`（前端拦截器统一跳登录，R9） |

### 4.2 发票 invoices（F04–F08/F10/F15）

| 方法 路径 | 说明 | 请求/响应要点（继承 v1.0） |
| --- | --- | --- |
| `GET /invoices` | 列表+筛选+分页（F07/F08） | query：`month`(YYYY-MM)、`title`(关键字)、`amountMin`、`amountMax`（作用 totalAmount）、`category`(可多，逗号分隔)、`medium`(可多)、`status`(可多)、`page`、`page_size`；条件间 AND、同维度多值 OR；`amountMin>amountMax` → `422 INV_003`（正常由前端前置拦截）；响应 `data: {items:[…], total, page, page_size}`；**items 中 `invoiceNumber` 服务端掩码 `****5678`**，`?show_sensitive=1` 返回全号（R8 眼睛切换） |
| `POST /invoices` | 新增（F04，G1） | 入参 11 字段（不含 totalAmount）；服务端 BigDecimal 重算价税合计；`issuedDate > 今天(东八区)` → `422 INV_002`；成功 `201` 返回完整资源（不脱敏，新记录即刻定位） |
| `GET /invoices/{id}` | 详情（F07） | 完整字段 + `attachments[]` 元数据；**不脱敏**（详情页口径）；非本人/不存在 → `404 INV_001` |
| `PATCH /invoices/{id}` | 编辑（F05，M2） | 部分字段合并；保留 `createdAt`、刷新 `updatedAt`；校验同 POST |
| `DELETE /invoices/{id}` | 删除→回收站（F06，M2） | 软删除（置 `deletedAt`）；附件随行保留；`204`；再删 → `404 INV_001` |
| `GET /invoices/export` | CSV 导出（F10，G3） | query 同列表筛选参数（无参=全量）；预检 `total>5000` → `422 EXP_001`；成功 `200 text/csv; charset=utf-8`，**首字节 BOM**，StreamingResponseBody 流式；列序：开票日期/发票代码/发票号码/抬头/票种/介质/状态/金额/税额/价税合计/备注/录入时间；**内容不脱敏**（本人导出）；文件名 `票夹通导出_YYYYMMDD_HHmmss.csv`（Content-Disposition，UTF-8 文件名编码） |
| `GET /invoices/titles/suggest` | 抬头联想（F15，M2 Could） | query `q`(≥2 字)；返回本人历史抬头 `data:["…"]`（去重、按频次+最近使用排序，≤10 条）；不阻断手输 |

### 4.3 附件 attachments（F11，M2）

| 方法 路径 | 说明 | 请求/响应要点（继承 v1.0） |
| --- | --- | --- |
| `POST /invoices/{id}/attachments` | 上传 | `multipart/form-data`，字段 `file`；服务端三校验：格式（扩展名+魔数 jpg/jpeg/png/webp/pdf）→ `422 ATT_003`；大小 >10MB → `422 ATT_001`；已挂 3 个 → `422 ATT_002`；成功 `201` 附件元数据 |
| `GET /invoices/{id}/attachments` | 附件列表 | 记录详情附属信息也可独立获取；`data:[元数据]` |
| `GET /attachments/{id}/file` | 下载/预览 | 属主谓词校验（记录属主 + userId 冗余双保险）；`200` 文件流，Content-Type 按存储 mime，inline 预览 |
| `DELETE /attachments/{id}` | 删除单个 | 存储层删文件 + DB 删行；`204`；记录本体与其他附件不受影响（R7） |

### 4.4 汇总 stats（F09，M2，G3）

| 方法 路径 | 说明 | 请求/响应要点（继承 v1.0） |
| --- | --- | --- |
| `GET /stats/summary` | 月/年卡片+分布 | 无必选参数（固定东八区当前自然月/年）；`data: { month:{totalCount, validCount, validAmount, voidedCount, reversedCount}, year:{同构}, distribution:[{category, medium, count, amount} ×4] }`；`validAmount` 为红冲冲减后净值（可为负，如 `"-2000.00"`，R10 负数正常渲染）；空数据返回全 0 + 空分布数组，不报错 |

### 4.5 回收站 recycle（F06/F12，M2）

| 方法 路径 | 说明 | 请求/响应要点（继承 v1.0） |
| --- | --- | --- |
| `GET /recycle/items` | 回收站列表 | 仅 `deletedAt` 非空的本人记录，按 `deletedAt` 倒序；每条含 `deletedAt`、`daysLeft`（30−已过天数，服务端计算）；`page`/`page_size` 同全局约定 |
| `POST /recycle/items/{id}/restore` | 恢复 | 置空 `deletedAt`（列表按开票日期排序天然回原位）；附件随之可用；`204`；`daysLeft≤0`（已被 cron 清理）→ `404 INV_001` |
| `DELETE /recycle/items/{id}` | 彻底删除 | 二次确认后的物理清除：事务删 DB 行（级联附件行）+ 删存储文件；`204`；不可恢复 |

### 4.6 埋点与运维 events / health / api-docs

| 方法 路径 | 说明 | 请求/响应要点 |
| --- | --- | --- |

## 6. 错误码规范（15 码，语义继承 v1.0）

格式：`域前缀_三位序号`。HTTP 状态码表意、业务 code 表因。v2.0 载体变化：常量收敛于 `server …/common/error/ErrorCode.java` 枚举（唯一实现点），并经 springdoc 描述随 `contracts/openapi.json` 分发给前端（orval 生成对应字面量联合类型）；**两处（枚举与契约工件）漂移以本文为语义基准并在 PR 中同步，CI 防线一拦截**。

| code | HTTP | 场景（对应验收） | message（用户可读，唯一口径） |
| --- | --- | --- | --- |
| `AUTH_001` | 401 | 账号或密码错误（F02） | 账号或密码错误 |
| `AUTH_002` | 423 | 连续 5 次失败锁定（F02） | 账号已锁定，请 {n} 分钟后重试 |
| `AUTH_003` | 401 | 未登录/会话过期（R9 全局 401 拦截） | 登录已过期，请重新登录 |
| `AUTH_004` | 409 | 标识已注册（F01） | 该邮箱/手机号已注册，请直接登录 |
| `AUTH_005` | 422 | 注册/登录格式校验失败（F01） | 账号或密码格式不正确 |
| `INV_001` | 404 | 记录不存在/非本人（F07、IA §6） | 记录不存在或已删除 |
| `INV_002` | 422 | 发票字段校验失败（F04/F05/R3 校验矩阵） | 提交内容有误（details 逐字段） |
| `INV_003` | 422 | 筛选参数非法（min>max、month 格式错） | 筛选条件有误（details 指明字段） |
| `ATT_001` | 422 | 单文件 >10MB（F11） | 单个附件不能超过 10MB |
| `ATT_002` | 422 | 每记录 >3 个（F11） | 每条发票最多 3 个附件 |
| `ATT_003` | 422 | 格式不支持（F11，含魔数不符） | 仅支持图片（jpg/png/webp）或 PDF |
| `EXP_001` | 422 | 导出 >5000 条（F10/R6） | 超过单次导出上限 5000 条，请缩小筛选范围 |
| `RATE_001` | 429 | 请求频率超限（Caddy/守卫层） | 操作太频繁，请稍后再试 |
| `SYS_001` | 500 | 未预期服务端错误（日志含 requestId） | 服务开小差了，请稍后重试 |
| `SYS_002` | 503 | 数据库/依赖不可用（health 探测） | 服务暂不可用，请稍后重试 |

规范细则：

1. **5xx message 永不泄露内部细节**（堆栈、SQL、异常类名）；`X-Request-Id` 响应头（MDC）供 support 反查 JSON 日志——继承；
2. `details[].field` 与前端表单字段名（=OpenAPI schema 字段名）严格一致，行内错误定位（R1/R3）；
3. 新增错误码必须同时登记本文、`ErrorCode.java` 枚举、OpenAPI 描述三处，PR 中三处联动（防线一/二 CI 校验枚举与契约工件一致）；
4. **v2.0 补充码（第 16 码，显式标注）**：写接口（POST/PATCH/DELETE）缺失 `X-Requested-With` 头由 XRequestedWithFilter 拒绝 → `403 AUTH_006`，message「请从票夹通页面发起操作」，details 为空。既有 15 码语义零变更；此码仅由工程层 CSRF 过滤器触发，正常前端（orval mutator 自动带头）永不出现；support 排查口径：「出现 AUTH_006 = 非票夹通页面发起的跨站提交」；

## 7. 安全约定（G4，继承 v1.0 + Java 落点）

1. 除 `POST /auth/register`、`POST /auth/login`、`POST /events`、`GET /health` 外，全部接口需登录（SessionResolver → 未登录 `401 AUTH_003`）；
2. 资源级接口（含 `{id}` 与 `{id}/file`）叠加属主谓词：`loadOwned(id, userId)` 查无 → `404 INV_001`（architecture §4.3 纪律）；
3. 列表类接口 `invoiceNumber` 默认服务端掩码；全号仅出现在详情、导出、`show_sensitive=1` 列表；
4. Cookie 不含业务数据（仅不透明 session ID）；日志不落密码、不落全号（掩码后可落）；
5. 登录接口按账号维度限速（users 表 failed_attempts/locked_until 计数锁定为主，Caddy 限流为辅）；
6. `GET /v3/api-docs` 生产环境经 Caddy 屏蔽（deny 或仅内网），防接口面信息泄露。

## 8. OpenAPI 契约生成约定（v2.0 新增章）

| 项 | 约定 |
| --- | --- |
| 生成方向 | springdoc 从 Controller 注解**单向生成**契约；禁止手改 `contracts/openapi.json` |
| 包络 schema | `ApiResponse<T>` 泛型记录在 OpenAPI 中展开为具体 schema（如 `InvoiceDetailResponse{data:InvoiceDetail}`）；错误包络 `ErrorResponse{error:{code,message,details[]}}` 全局注册 |
| 金额 | DTO 字段用 `String` + `pattern: ^\d{1,10}\.\d{2}$`（Jackson BigDecimal 模块保证序列化形态） |
| 时间 | `issuedDate` → `type:string, format:date`；`createdAt` 等 → `type:string, format:date-time`（UTC） |
| 枚举 | category/medium/status/accountType 用 OpenAPI enum 字面量（normal/voided/reversed…），前端生成联合类型 |
| 校验注解 | Bean Validation 注解（@Pattern/@Size/@DecimalMin）由 springdoc 自动映射进 schema——传输层规则进契约，业务规则（≤今天、附件计数）在 service 复核不进 schema |
| 变更流程 | 改 Controller 注解 → `./mvnw verify -Popenapi-export` 导出 → `pnpm gen:api` 重新生成 → 连同业务代码一并提 PR（四步，repo-layout §5.4） |
| 漂移检测 | CI 防线一（契约工件 diff）+ 防线二（generated diff）+ 防线三（前端手写 schema 类型对齐）——tech-stack §7.3 |
